Prism Tide is an original HTML5 arena orb-collector game built for make.fun's "Make the best game" bounty: move the prism, collect orbs matching the active colour, dodge dark shards and hunters, and clear 10 waves to win. Three lives, dash, and power-ups Shield, Slow Tide and Prism Surge, with start, pause, win and game-over screens.

## Run it

```sh
node serve.ts
